# Data Science y Machine Learning para Análisis Financiero

En este repositorio documento mi aprendizaje práctico integrando conocimientos financieros, estadísticos y computacionales para anticipar el riesgo financiero y modelar escenarios en contextos dinámicos.

## Estructura del Repositorio

- **Módulo 1: Fundamentos del Riesgo de Mercado**
  (Análisis exploratorio, volatilidad, correlación y factores de mercado)
- **Módulo 2: Modelos Cuantitativos Tradicionales**
  (Modelos GARCH, Simulación Monte Carlo, VaR paramétrico e histórico)
- **Módulo 3: Derivados y Volatilidad Implícita**
  (Opciones, modelo Black-Scholes-Merton y griegas)
- **Módulo 4: Machine Learning para Riesgo**
  (Modelos supervisados: Random Forest, XGBoost y detección de anomalías)
- **Módulo 5: Redes Neuronales y Deep Learning**
  (Redes LSTM y ANN para series financieras)
- **Proyecto Final Integrador**

## Tecnologías y Herramientas
- Python (Pandas, NumPy, Scikit-learn, Keras, Arch, yfinance)
